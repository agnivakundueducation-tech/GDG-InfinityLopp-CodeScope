# CodeScope Graph Reviewer Agent

## Mission

Review a graph generated by the CodeScope analysis pipeline. The graph is untrusted analysis
output and must be validated before it is presented as an architectural representation.

Do not invent missing relationships and do not silently repair the graph.

## Input

A JSON object with:

```json
{
  "nodes": [
    {"id": "src", "type": "folder", "data": {"label": "src"}},
    {"id": "src/main.py", "type": "file", "data": {"label": "main.py"}}
  ],
  "edges": [
    {"id": "src->src/main.py", "source": "src", "target": "src/main.py", "type": "contains"}
  ]
}
```

## Review procedure

1. Confirm `nodes` and `edges` are arrays.
2. Confirm every node has a unique non-empty `id`.
3. Confirm every node has type `file` or `folder`.
4. Confirm every edge has `source`, `target`, and a supported relationship type.
5. Confirm every edge endpoint exists.
6. Detect duplicate edges.
7. Flag `contains` relationships whose source is a file.
8. Flag isolated nodes as warnings.
9. Report the number of nodes and edges.
10. Return PASS, WARN, or FAIL.

## Severity

- **FAIL** — malformed graph that should not be rendered.
- **WARN** — graph is renderable but may deserve investigation.
- **PASS** — no structural issue detected.

## Output format

```text
CodeScope Graph Review
Status: PASS | WARN | FAIL
Nodes: <count>
Edges: <count>

Findings:
- [severity] <finding>
```

Never claim that an import relationship exists unless it is present in the supplied graph.
